# atlante-citt--sensibili
# Città che cambiano

Un atlante interattivo delle città europee e delle loro esperienze di sostenibilità, ispirato alla rubrica Facebook di Pino Bruno e al progetto Amnesia creativa.

La mappa raccoglie sintesi dedicate a sei temi: acqua, rifiuti, verde e rigenerazione, energia, mobilità e calore urbano.

## Esplorare la mappa

- Seleziona i temi per filtrare i punti sulla mappa.
- Clicca su una città per leggere le sintesi disponibili.
- Usa il pulsante informativo accanto a un tema per approfondirlo.
- Regola la dimensione dei testi con i pulsanti A−, A e A+.

## File del sito

| File | Contenuto |
| --- | --- |
| `index.html` | Struttura della pagina e collegamenti alle risorse |
| `stile.css` | Aspetto grafico e impaginazione |
| `mappa.js` | Dati, mappa interattiva, filtri e contenuti |

I tre file devono rimanere nella stessa cartella. Non è necessaria una compilazione.

## Pubblicazione con GitHub Pages

1. Carica `index.html`, `stile.css` e `mappa.js` nella cartella principale del repository.
2. Apri **Settings → Pages**.
3. Seleziona **Deploy from a branch**, il branch **main** e la cartella **/ (root)**.
4. Salva e attendi il completamento della pubblicazione.
5. Apri l'indirizzo mostrato da GitHub nella sezione Pages.

## Risorse esterne

Il sito utilizza Leaflet e Leaflet.markercluster, caricati tramite cdnjs, font di Google Fonts e cartografia Esri tramite servizi ArcGIS. Per visualizzare tutte le funzionalità è necessaria una connessione Internet.

Le librerie, i font e la cartografia mantengono le rispettive licenze e condizioni d'uso. Le attribuzioni della cartografia devono essere mantenute.
